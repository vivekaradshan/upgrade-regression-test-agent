System architecture — v2

Upgrade Regression Test Agent

Real infrastructure this system runs on: an AWS Step Functions state machine orchestrating nine Lambda handlers and two EMR Serverless Spark applications, backed by DynamoDB, S3, and Secrets Manager — plus GitHub, OpenAI, Tavily, and LangSmith as external dependencies. Triggered via streamlit run dashboard/app.py or cli.py --target aws.

Step Functions

upgrade-agent-orchestrator (state machine)

BRANCH› BUILD› EXECUTE› ANALYZE› AWAIT_APPROVAL› VALIDATE› REPORT› PR

AWAIT_APPROVAL uses waitForTaskToken — the execution genuinely pauses, no polling, until a human clicks Approve, Retry with my fix, or Reject on the dashboard.
